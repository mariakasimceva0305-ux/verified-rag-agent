# Поиск по документам с цитированием

Локальный конвейер: эвристическое уточнение вопроса, поиск фрагментов, лексическое переранжирование и извлечение текста с цитатами. Отдельная проверка оценивает совпадение формулировок ответа с найденными фрагментами.

## Оценка

На демонстрационных 16 вопросах baseline даёт MRR 0,9375, вариант с уточнением и переранжированием — 0,9688. HitRate@K равен 1,0 в обоих случаях. Эти числа описывают небольшой набор, а не качество на новых документах.

HitRate считается по выдаче до rerank, MRR — по финальному порядку. grounded_rate=1,0 означает прохождение лексической проверки извлечённого ответа; это не независимая оценка достоверности. Генеративная модель и LLM-судья в этом контуре не используются.

## Запуск

```bash
pip install -r requirements.txt
export PYTHONPATH=.
python scripts/ingest.py --config configs/baseline.yaml
python scripts/build_index.py --config configs/baseline.yaml
python scripts/run_eval.py --config configs/baseline.yaml
```

Для PowerShell: `$env:PYTHONPATH="."`. Повторите подготовку и оценку с `configs/improved.yaml`, чтобы сравнить режимы. Отчёты — `eval/results/summary_baseline.json`, `summary_improved.json` и соответствующие файлы выдачи. Демо — `python scripts/demo.py --config configs/improved.yaml` после подготовки индекса этой конфигурации.

Код — `src/`, набор вопросов — `eval/questions.jsonl`, параметры — `configs/`. Для оценки достоверности ответов нужен отдельный размеченный набор, включая вопросы без ответа и противоречащие источники.
